## 2. Exact new preregistered, independently tested analysis — essential Route A question

The earlier `stage19_v2/training_exposure_strata.py` can measure **actual 240,000 model-training sampled-vector exposure** but not the distinct full eight-source-corpus availability measure. Given that 2025 literature already implements N-BaIoT federated nine-fold leave-one-device-out, a generic LODO result is not sufficient to establish novelty.

**New** `stage19_v2/full_source_vs_training_exposure.py` implements the explicitly pre-result class-conditional comparison of three mutually exclusive held-out target feature groups:

1. **trained_exact:** native target's canonical original 115D raw float64 feature vector is among *the actual 8×30,000 examples used to fit the model* at that fold and seed.
2. **available_not_used:** numerical vector exists in **the entire original corpus of at least one of the eight other devices**, but not among this run's actually selected 240,000 training examples.
3. **unavailable:** numerical vector is absent from all eight original nonheldout device corpora.

Canonical equality is BLAKE2b-128 over little-endian float64 after signed-zero normalization, like Stage13/18. **This is numerical feature equality, not identity of captured packets, a novel algorithm, randomized leakage exposure or a causal explanation.** The three classes partition each native target class without dropping any observation. Their rate types are **attack recall** for each original attack class and **benign false-positive rate** for benign. Empty or absent cells get `NON_ESTIMABLE`; no fabricated zeros. Neither group exposure nor class support is used for training, source normalization, model selection or threshold tuning.

The program creates a private SQLite digest-only device membership bitmask index of all original nine device datasets **only after verifying all 54 original authorized, independently replayed target runs exist**. It checks the authentic nine outer ZIP byte SHA-256 and original native class support before scanning, and excludes a device's *own* observations from full-source availability for its heldout fold.

It requires the SHA-locked Stage18 approval of the source manifest and all code and Stage19 scripts; compares FedAvg/FedProx exposure denominators at matched seed/device, and never turns this diagnostic into a causal assertion. Fingerprint membership SQLite and source-sample digests are private research data (do not upload this indexed membership artifact to public GitHub).

**Actual execution status:** New tool runs on fixture data only. There are no native heldout score files to feed this tool. The recorded Stage13 **42 full-source recurrent/unseen eligible attack cells** must not be copied as the actual model-sampled availability supports.
